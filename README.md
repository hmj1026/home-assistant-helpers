# Domotics Helpers

A Claude Code plugin with skills for Home Assistant. / 給 Claude Code 使用的 Home Assistant 技能套件。

```text
/plugin marketplace add hmj1026/home-assistant-helpers
/plugin install domotics-helpers@domotics-helpers
```

- Plugin and docs / 套件與說明：[plugins/domotics-helpers](plugins/domotics-helpers/README.en.md) · [繁體中文](plugins/domotics-helpers/README.md)
- Development / 開發：[CONTRIBUTING.md](CONTRIBUTING.md)

## Layout

- `plugins/domotics-helpers/`: the plugin that ships (submitted to the plugin directory).
- `evals/`: evaluation cases, repo only, not shipped.
- `.claude-plugin/marketplace.json`: the marketplace that lists the plugin.
