# Changelog

## 0.2.0 (2026-11-20)

- **Breaking**: the plugin is renamed from `home-assistant-helpers` to `domotics-helpers`, with display name "Domotics Helpers". Reinstall it as `domotics-helpers@domotics-helpers`. The skill is now `domotics-helpers:ha-dashboard-studio`.
- The plugin now lives in `plugins/domotics-helpers/`. Evaluation cases stay in the repository and are no longer shipped.
- Developer notes move to the repository's CONTRIBUTING.md.

## 0.1.0 (2026-11-18)

- First release of the plugin, published as `home-assistant-helpers`.
- New skill `ha-dashboard-studio`: survey → concepts → approved plan → build → handover, plus restyle; five styles (native-minimal, frosted-glass, soft-mushroom, wall-kiosk, control-room), five layouts (rooms, moments, people, single-screen, app), five palettes and three densities that can be mixed freely.
- Evaluation cases under `evals/`.
